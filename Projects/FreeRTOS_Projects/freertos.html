FreeRTOS Kernel Extension

Objective

The objective of this project was to extended the FreeRTOS kernel to support dynamic-task priority scheduling and resource access control. Specifically it had to support the following:

  • Earliest Deadline First (EDF) scheduler on a single core, partitioned (fixed) multi-core, and global (variable) multi-core.
  • Stack Resource Policy (SRP) on a single core for binary semaphores only.
  • Constant Bandwidth Server (CBS) on a single core for servicing soft real-time requests on top of the hard real-time tasks scheduled by EDF.
